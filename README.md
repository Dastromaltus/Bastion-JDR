1 - Bastion – inspiration, fonctionnement et autres informations
Introduction : Bastion est née d’une passion pour les jeux de plateau ainsi que les jeux de rôles type dungeon crawler, c’est un jeux qui ce joue de 3 à 5 personnes avec les joueurs (aventuriers) qui affronteraient le narrateur (celui qui incarne les évènement inconnues, le lieux ou ce déroule l’aventure, les ennemies etc.). Gameplay :
3 – 5 joueurs
style artistique : brutalisme rouge et noir


races :
    • Humain : polyvalent, sans gros malus.
    • Insecte : rapide, fragile, bon en poison ou embuscade.
    • Reptile : résistant, lent, bon en défense.
    • Crustacé : très tanky, faible mobilité. 
    • Oiseau : mobilité élevée, défense plus faibl

states :
    • vitesse
    • force
    • endurance

Structure de partie
Pour rendre le jeu plus fluide, tu peux organiser la partie autour de 3 phases :
    • Préparation : choix du rôle, de la race, des compétences.
    • Affrontement : actions et résolution des effets.
    • Scénario : objectif spécial du gamemaster, comme défendre un trésor, survivre, ou accomplir une quête.


Méthode simple de test
Teste ton jeu avec cette logique :
    • 1 partie courte,
    • 1 race différente à chaque joueur,
    • 1 compétence forte par joueur maximum,
    • note ce qui gagne trop souvent,
    • ajuste ensuite les coûts, durées ou restrictions.
